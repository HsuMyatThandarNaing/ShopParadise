# 🛍️ Shop Paradise – Online Shopping Website

## About the Project

Shop Paradise is an online shopping website developed to provide a simple and convenient shopping experience. It brings different types of products together in one place, allowing customers to browse and choose products from various categories.

The website includes cosmetics, beauty products, food and snacks, fashion items, fruits and vegetables, and books. Each category has its own product page where users can explore available items and add their desired products to the shopping cart.

## Main Features

- **Homepage:** Provides an overview of the website and easy navigation to different product categories.
- **Product Categories:** Organizes products into different sections for convenient browsing.
- **Popular Items:** Displays selected products that customers can explore and purchase.
- **Shopping Cart:** Allows users to add products, change quantities, remove items, and view the total price.
- **Login and Signup:** Provides forms for users to enter their account information.
- **Checkout and Payment:** Includes a simple checkout process and a sample payment form.
- **Review Page:** Allows customers to share their shopping experiences.
- **About Us:** Provides information about the website.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

Open `HomePage.html` in a web browser or use the Live Server extension in Visual Studio Code.

**Note:** Login, signup, and payment features are frontend demonstrations. They do not use real authentication or process actual payments.
